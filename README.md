# Поштова місія — інтерактивна гра з інформатики (6 клас)

Навчальна браузерна гра за темою:

- Надсилання та отримання електронних повідомлень.
- Перенаправлення повідомлень: відповідь, пересилання, копія.
- Пересилання файлів і правила безпечної роботи з вкладеннями.
- Використання адресної книги.
- Списки розсилки та прихована копія (BCC).

## Запуск

Гру можна відкрити без встановлення програм:

1. Відкрийте **Settings → Pages** у репозиторії.
2. У розділі **Build and deployment** виберіть **Deploy from a branch**.
3. Branch: `main`, папка: `/(root)`.
4. Натисніть **Save**.
5. Після публікації гра буде доступна за адресою:

   https://dmytro-rusnak-physics.github.io/computer-science-6-google-contacts/

Також можна завантажити репозиторій і відкрити `index.html` у браузері.

## Для учнів

Пройдіть п'ять місій. У кожній — чотири запитання по 10 балів. Максимальний результат — 200 балів. Гра не підключається до реальної пошти й не надсилає повідомлень: усі завдання навчальні.

## Файли

- `index.html` — структура сторінки.
- `style.css` — адаптивне оформлення.
- `script.js` — логіка гри, завдання та підрахунок балів.

## Технології

HTML, CSS і JavaScript. Без фреймворків, збірки та сторонніх бібліотек.
